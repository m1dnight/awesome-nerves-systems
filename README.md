# Awesome Nerves Systems

Nerves has been brought to a variety of devices over the years. These systems are obviously not official, sometimes old and not always maintained by their authors.

This file centralizes where these systems are so people can use them, pick up where they left off, or simply learn from them.

Want to add something to the list? Just send a PR :smiley:
